## Author
Daniel Soares. Email me if you have any questions (dcs3personal@gmail.com).

## Description
Replacing the To-Do List system on Canvas. This Google Chrome extension pulls due dates from the calendar to create a clickable checklist that helps you complete your assignments. Completed assignments appear as a bar graph and are added to their own list in case you forget something. Courses are color-coded based on the built in colors for each module.
